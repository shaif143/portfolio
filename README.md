# Shaif Ahamed Tamim — Portfolio

A cinematic, motion-rich portfolio for an AI engineer, researcher, and builder
based in Dhaka, Bangladesh.

## Live portfolio

**[shaif-ahamed-tamim.hyperglow1.chatgpt.site](https://shaif-ahamed-tamim.hyperglow1.chatgpt.site)**

The experience includes:

- a glass-and-black-chrome 3D landing scene;
- professional experience, education, awards, and research;
- an in-depth AI clinical report summarization capstone;
- a living photography archive;
- a private owner studio for CV and gallery uploads;
- responsive motion with reduced-motion accessibility.

## Technology

- React 19 and Next.js-compatible App Router
- vinext and Vite
- Cloudflare Workers
- R2-backed CV and photography uploads
- CSS 3D transforms and Canvas motion

## Local development

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run build
```

## GitHub Pages

The root `index.html` is a lightweight gateway that redirects GitHub Pages
visitors to the full production experience. The full application is hosted on
Cloudflare because its secure owner studio and persistent uploads require a
server runtime and object storage.
